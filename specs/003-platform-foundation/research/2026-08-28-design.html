01목표·범위·완료 기준✔ 승인됨 (2026-08-28)

목표

SP-1은 두 가지를 동시에 끝낸다. 결정의 고정 — 스택·경계·운영 원칙을 ADR 9개, .specify/memory/{product,architecture}.md, .claude/rules·agents·approval boundary로 남긴다. 뼈대의 실물 — 클러스터·GitOps·인그레스·시크릿·데이터·이벤트·신원 플랫폼이 실제로 돌고, 웹 hello가 BFF를 거쳐 pod의 /health까지 왕복하며, pod 템플릿이 RLS·outbox 테스트를 통과한다.

범위 밖

  • pod의 도메인 기능(content·projects·contact·media 업로드·댓글) — SP-2. SP-1은 identity-admin의 health 엔드포인트와 템플릿만.
  • Elasticsearch/ECK/Kibana, notification, insights — SP-3. 노드 RAM 예산에는 자리를 남긴다.
  • assistant(pgvector·SSE), tenant-billing, 멀티테넌트(B) 전환 — SP-4+.
  • v1 데이터 이행 — 없음(사용자 결정: 백업·임포트 없이 종료).

BFF = 게이트웨이

세션
확정 egenauto authx 모델과 동형(IdP만 Authentik): 세션·refresh 토큰의 정본은 Authentik(서버측, Postgres 행), BFF 쿠키는 암호화된 refresh(HttpOnly·SameSite=Lax·Secure), access 토큰은 5분 TTL로 isolate 캐시. 갱신·로그아웃·전체 기기 로그아웃은 BFF → Authentik(refresh 회전, revoke). 기기 목록은 Authentik 사용자 Sessions 화면. 저장소 컴포넌트 추가 없음.
즉시 폐기
확정 Google(불투명 토큰 중앙 검증 + RISC 이벤트 전파)·Naver(불투명 토큰 + delete)와 같은 효과를 JWT로 얻는 합성: 로그아웃·관리자 폐기·Authentik 세션 삭제(웹훅) → identity-admin이 Authentik revoke 호출 + Dragonfly에 revoked:{sub} not-before(또는 revoked:{sid}) 기록(TTL = access TTL) + Kafka identity-admin.session.revoked 발행 → 모든 pod의 인증 미들웨어(django-common)가 JWT 서명·iss·aud 검증 뒤 Dragonfly GET 1회로 거부 → BFF도 요청 전 identity-admin /session/check(2초 캐시). 반영 ≈ 1초, Authentik은 핫 경로 밖.
Authentik 객체
Application+Provider: web-bff(confidential, token exchange grant), pod마다 1개(identity-admin·portfolio-core…, 자기 issuer·JWKS), 관리 앱(argocd·vault·kibana·grafana는 OIDC/forward-auth). Scope mapping tenant_id. Federated Providers = 교환 토폴로지(대상별 허용 호출자). Blueprints 저장소로 선언(identity-admin이 적용, SP-2). OSS에서는 act 클레임이 없으므로 impersonation 교환 + 호출자 식별은 Access 서비스 토큰 ID로 한다.
Cloudflare Access
공개 pod 호스트는 정책 Service Auth(BFF 서비스 토큰만), 관리 호스트(admin-*·argo·vault·kibana·Traefik 대시보드)는 GitHub IdP 로그인 + Authentik SSO 이중. Zero Trust Free 50석.
호스트
joshuatech.dev(웹·Workers) · auth.(Authentik) · <pod>-api. / <pod>-apidev.(pod, prod/dev) · admin-<pod>.(Django admin) · argo. vault. kibana.(관리) · cdn.(R2 공개 버킷). 전부 Cloudflare proxied, 오리진 인증서는 cert-manager 와일드카드, SSL Full(strict).
